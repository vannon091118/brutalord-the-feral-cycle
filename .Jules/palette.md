## 2024-05-18 - [Accessibility: ARIA Labels for Icon Buttons]
**Learning:** Icon buttons or buttons whose function isn't clear from context alone need explicit aria-labels for screen readers. Further, WCAG 2.5.3 requires aria-labels to include the visible text of the element, otherwise it's a violation.
**Action:** When adding aria labels for UX improvement to elements with dynamically rendered text, include the visual text as well.
